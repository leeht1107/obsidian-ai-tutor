# LibreOffice 설치 (Mac)

AI 튜터의 문서 스킬(엑셀·워드·PPT)이 엑셀 수식을 다시 계산하거나 문서를 PDF로 바꿀 때 LibreOffice를 씁니다.
무료이고, 한 번만 설치하면 됩니다. 터미널은 쓰지 않습니다.

## 1. 내 Mac의 칩 확인

- 화면 왼쪽 위 사과 모양() → **이 Mac에 관하여**
- **칩**에 `Apple M…`이 보이면 Apple 칩입니다.
- **프로세서**에 `Intel`이 보이면 Intel 칩입니다.

## 2. 내려받기

- https://www.libreoffice.org/download/download-libreoffice/ 에 들어갑니다.
- 운영체제 목록에서 고릅니다.
  - Apple 칩: **macOS (Apple Silicon)**
  - Intel 칩: **macOS x86_64**
- 큰 **다운로드** 버튼을 누릅니다. `.dmg` 파일 하나가 받아집니다.

## 3. 설치

- 받은 `.dmg` 파일을 두 번 클릭합니다.
- 열린 창에서 **LibreOffice** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓습니다.
- 복사가 끝나면 창을 닫습니다.

## 4. 처음 한 번 열기

- **응용 프로그램** 폴더에서 LibreOffice를 두 번 클릭합니다.
- "열 수 없습니다" 같은 창이 뜨면:
  - **시스템 설정** → **개인정보 보호 및 보안**으로 갑니다.
  - 아래쪽의 **그래도 열기**를 누릅니다.
- LibreOffice 첫 화면이 보이면 닫아도 됩니다.

## 5. AI 튜터에서 확인

- Obsidian **설정** → **AI 튜터** → **스킬**에서 **LibreOffice** 줄의 **다시 확인**을 누릅니다.
- `찾음`이 보이면 끝입니다. 다음 대화부터 문서 스킬의 모든 기능이 동작합니다.

## 막히면

- 채팅에 "LibreOffice 설치가 안 돼"라고 쓰고, 화면에 보이는 문구를 그대로 붙여 넣으세요.
