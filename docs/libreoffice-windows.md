# LibreOffice 설치 (Windows)

AI 튜터의 문서 스킬(엑셀·워드·PPT)이 엑셀 수식을 다시 계산하거나 문서를 PDF로 바꿀 때 LibreOffice를 씁니다.
무료이고, 한 번만 설치하면 됩니다. 명령 창은 쓰지 않습니다.

## 1. 내려받기

- https://www.libreoffice.org/download/download-libreoffice/ 에 들어갑니다.
- 운영체제 목록에서 **Windows x86_64**를 고릅니다. (대부분의 노트북은 이것입니다.)
- 큰 **다운로드** 버튼을 누릅니다. `.msi` 파일 하나가 받아집니다.

## 2. 설치

- 받은 `.msi` 파일을 두 번 클릭합니다.
- **다음**을 누릅니다.
- 설치 형태는 **일반**을 그대로 두고 **다음** → **설치**를 누릅니다.
- "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 **예**를 누릅니다.
- **마침**을 누릅니다.

## 3. AI 튜터에서 확인

- Obsidian **설정** → **AI 튜터** → **스킬**에서 **LibreOffice** 줄의 **다시 확인**을 누릅니다.
- `찾음`이 보이면 끝입니다. 다음 대화부터 문서 스킬의 모든 기능이 동작합니다.
